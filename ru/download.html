Системные требования

  • Windows 10 версии 1809 или Windows 11 (x64).
  • Windows App SDK runtime — устанавливается автоматически при первом запуске, если отсутствует.
  • .NET 10 Desktop Runtime.
  • Ollama, установленная и запущенная локально.
  • Свободное место на диске: 500 МБ на приложение + место под модели (каждая 7B-модель ≈ 4–5 ГБ).

Как установить

  1. Скачайте ZIP-архив последней версии по кнопке выше.
  2. Распакуйте его в любую папку (например, C:\Programs\AI_IT_Company).
  3. Запустите AI_IT_Company.exe.
  4. Если Windows SmartScreen ругается — нажмите Подробнее → Выполнить в любом случае (сборки не подписаны).
  5. Следуйте Быстрому старту для настройки Ollama и агентов.

Сборка из исходников

Вы всегда можете клонировать репозиторий и собрать приложение самостоятельно — сторонних зависимостей, кроме NuGet, нет:

git clone https://github.com/YOURUSER/AI_IT_Company.git
cd AI_IT_Company
dotnet restore
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained

Проверка целостности

В каждый релиз включён файл контрольных сумм SHA-256 (SHA256SUMS.txt). Проверить в PowerShell:

Get-FileHash .\AI_IT_Company-x.y.z.zip -Algorithm SHA256
