Почему AI IT Company

Не очередная обёртка над ИИ, а полноценный конвейер: архитектор → кодеры → тестировщик → сборщик → исправитель → секретарь.

🔒

100% локально

Ваш код и идеи не покидают компьютер. Ни облака, ни аккаунтов, ни телеметрии.

💸

Бесплатно навсегда

Работа через Ollama — без API-ключей, подписок и лимитов на токены.

🎯

Правильная модель для каждой задачи

Для каждого агента можно назначить свою модель: маленькая для интерпретации, большая для кодинга.

🧩

Поэтапная разработка

Каждый этап оставляет собирающуюся программу и git-коммит. Провал одного этапа не убивает остальные.

🩹

Авто-исправление ошибок сборки

Если сборка упала — агент-исправитель читает лог и патчит код. До 3 попыток на этап.

⚡

Скромное железо

Проверено на Ryzen 5, 32 ГБ DDR4, 1 ГБ VRAM с моделями qwen2.5-coder:7b и :14b.

Команда агентов

Каждая роль — отдельный агент со своим системным промптом и, при желании, своей моделью.

🧭
ИнтерпретаторРазбирает запрос, определяет режим и тип проекта.
🏛
АрхитекторПишет ТЗ и разбивает работу на независимые этапы.
🏗
СкаффолдерСоздаёт каркас проекта через dotnet new.
⚙
Кодер-BackendПишет сервисы, работу с данными, API.
🎨
Кодер-FrontendПишет WinUI 3 XAML + MVVM через CommunityToolkit.
🎮
Кодер-GameПишет игры на MonoGame DesktopGL.
🧪
ТестировщикГенерирует xUnit + FluentAssertions + Moq тесты.
🔧
СборщикВыполняет dotnet build, коммитит в git при успехе.
🩹
ИсправительЧитает лог сборки, патчит сломанные файлы.
📝
СекретарьПишет итоговый REPORT.md со всеми фактами и статистикой.
