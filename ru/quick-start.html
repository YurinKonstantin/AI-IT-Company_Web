Быстрый старт

Установка за 5 минут

1. Что понадобится

  • Windows 10/11 (x64).
  • .NET 10 SDK — скачать.
  • Ollama — скачать.
  • Git — нужен для поэтапного версионирования.
  • Рекомендуется 16+ ГБ RAM (32 ГБ для моделей 14B).

2. Установите модель

Откройте терминал и загрузите модель для кодинга. Мы рекомендуем qwen2.5-coder:

ollama pull qwen2.5-coder:7b
# или, если у вас 32 ГБ RAM:
ollama pull qwen2.5-coder:14b

Убедитесь, что Ollama запущена: ollama serve (или значок в трее).

3. Получите приложение

Два варианта:

  1. Скачайте готовую сборку со страницы Releases, распакуйте и запустите AI_IT_Company.exe.
  2. Соберите из исходников: 
    git clone https://github.com/YOURUSER/AI_IT_Company.git
cd AI_IT_Company
dotnet build -c Release

4. Первый запуск

  1. Запустите приложение.
  2. Откройте Настройки и проверьте URL Ollama (по умолчанию http://localhost:11434). Нажмите Проверить — должно быть ✅.
  3. Перейдите в Модели — увидите список установленных моделей. Здесь же можно скачать или удалить модели.
  4. Перейдите в Агенты. Для каждого агента (Архитектор, Backend, Frontend, ...) выберите модель, которая будет его выполнять. Разные агенты могут использовать разные модели.

5. Создайте первый проект

  1. Откройте вкладку Чат.
  2. Опишите задачу простыми словами, например: «Создай WinUI 3 приложение для учёта ежедневных расходов с графиком трат по месяцам».
  3. Нажмите Запустить. Следите за конвейером: Интерпретатор → Архитектор → Скаффолдер → Кодеры → Тестировщик → Сборщик → (Исправитель) → Секретарь.
  4. По завершении откройте папку вывода (путь показан в логах). Внутри — сгенерированный проект, git-репозиторий с коммитами по этапам, TZ.md (техзадание) и REPORT.md.

7. Если что-то пошло не так

  • Ollama недоступна — проверьте, что ollama serve запущен и порт совпадает с настройками.
  • Модель не помещается в память — выберите меньшую квантизацию (например, :7b-q4) или уменьшите ContextWindow в настройках агента.
  • Сборка постоянно падает — Исправитель делает до 3 попыток на этап. Если ошибка всё равно есть — посмотрите REPORT.md и сырой ответ модели в папке вывода.
