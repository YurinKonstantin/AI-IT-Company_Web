System requirements

  • Windows 10 version 1809 or Windows 11 (x64).
  • Windows App SDK runtime — installed automatically by the app on first run if missing.
  • .NET 10 Desktop Runtime.
  • Ollama installed and running locally.
  • Free disk space: 500 MB for the app itself + space for models (each 7B model ≈ 4–5 GB).

How to install

  1. Download the latest ZIP archive from the button above.
  2. Unpack it into any folder (e.g. C:\Programs\AI_IT_Company).
  3. Run AI_IT_Company.exe.
  4. If Windows SmartScreen asks — click More info → Run anyway (builds are unsigned).
  5. Follow the Quick Start to configure Ollama and agents.

Building from source

You can always clone and build the app yourself — no third-party dependencies beyond NuGet:

git clone https://github.com/YurinKonstantin/AI-IT-Company
cd AI_IT_Company
dotnet restore
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained

Verifying builds

Each release includes SHA-256 checksums (SHA256SUMS.txt). Verify with PowerShell:

Get-FileHash .\AI_IT_Company-x.y.z.zip -Algorithm SHA256
