Privacy Policy

Last updated: 2026

Short version

The application does not collect, store, or transmit any of your data. AI IT Company runs entirely on your local computer and communicates only with a locally installed Ollama instance.

1. What the application does

AI IT Company is a desktop tool that sends your prompts to a local large language model (via Ollama) and saves the generated code to your local disk. All data — prompts, generated code, logs, git commits — stays on your machine.

2. What we do not collect

  • No telemetry, no analytics, no crash reports are sent anywhere.
  • No user account is required. There is no login, no sign-up.
  • No personal data is transmitted to the author or any third party.
  • No advertising identifiers, cookies, or tracking pixels.

3. Network connections

The application makes network requests only in the following cases:

  • To your local Ollama instance (default http://localhost:11434) — for model inference and management.
  • To the Ollama model registry — only when you explicitly click "Pull model" — to download the model weights you selected.
  • To GitHub — only when you explicitly click "Check for updates" or open a GitHub link from the app.

Any external network activity is initiated by your explicit action.

4. Local storage

The application stores locally on your computer:

  • Application settings (Ollama URL, agent configurations, custom prompts) in %LocalAppData%\AiItCompany.
  • Generated projects in the output folder you configure (default %LocalAppData%\AiItCompany\Output).
  • Log files, retained for 14 days.

You can delete these folders at any time without affecting the application.

5. Third-party services

The application uses Ollama to run models locally. Ollama itself is a separate open-source product with its own privacy policy. AI IT Company does not send any data to services other than your local Ollama instance.

If you configure the application to use a remote endpoint (e.g. an OpenAI-compatible server on a different host), the privacy policy of that endpoint applies to data sent to it.

6. Children's privacy

The application is not directed to children under 13. It contains no online features that would collect information from children.

7. Changes to this policy

If this policy changes, the updated version will be published on this page with a new "Last updated" date. Since we collect no data, changes will primarily reflect changes in features that affect network behavior.

8. Contact

Questions about privacy can be raised as issues in the GitHub repository.
