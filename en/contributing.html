Contribute

Every kind of help matters — from a bug report to a new agent.

Ways to help

  • Test models on your hardware and share results — which models work best for which agents at which parameter sizes. This is the most valuable contribution right now.
  • Report bugs — open an Issue with the log, the raw model output (dumped to _raw_*.txt), and your hardware/model config.
  • Improve prompts — if you found a system-prompt tweak that makes an agent behave better, share it.
  • Add features — new agent roles, new project types, better UI.
  • Translate — help expand localization of the app and the website.

Fork & PR workflow

  1. Fork the repo on GitHub.
  2. Create a feature branch: git checkout -b feature/my-improvement.
  3. Make focused, small commits with clear messages.
  4. Push to your fork and open a Pull Request against main.
  5. Describe what you changed, why, and how you tested it.

Coding style

  • Follow standard C# conventions (PascalCase for types/methods, _camelCase for private fields).
  • Prefer async/await, CancellationToken everywhere, no .Result or .Wait().
  • Keep methods short. Extract helpers over adding comments.
  • Nullability enabled — annotate nullable types explicitly.

Reporting model behavior

When reporting an issue caused by a specific model, please include:

  • Model name and exact tag (e.g. qwen2.5-coder:14b-q4_K_M).
  • Which agent was affected.
  • Your prompt.
  • The raw output file (_raw_*.txt or _architect_bad_json_*.txt) from the output folder.
  • Your hardware (CPU / RAM / GPU VRAM).

Code of conduct

Be kind. Be constructive. Assume good intent. No harassment, discrimination or personal attacks — such contributions will be rejected regardless of technical quality.
