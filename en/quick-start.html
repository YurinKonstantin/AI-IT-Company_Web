Quick Start

5-minute setup guide

1. Prerequisites

  • Windows 10/11 (x64).
  • .NET 10 SDK — download.
  • Ollama — download.
  • Git — required for per-stage version control.
  • 16+ GB RAM recommended (32 GB for 14B models).

2. Install a model

Open a terminal and pull a coding model. We recommend qwen2.5-coder:

ollama pull qwen2.5-coder:7b
# or, if you have 32 GB RAM:
ollama pull qwen2.5-coder:14b

Make sure Ollama is running: ollama serve (or launch the tray app).

3. Get the application

Two options:

  1. Grab the ready-made build from the Releases page, unpack and run AI_IT_Company.exe.
  2. Build from source: 
    git clone https://github.com/YurinKonstantin/AI-IT-Company
cd AI_IT_Company
dotnet build -c Release

4. First run

  1. Launch the app.
  2. Open Settings and verify the Ollama URL (default http://localhost:11434). Click Check — you should see ✅.
  3. Go to Models — the list of installed models will appear. From here you can pull or delete models.
  4. Go to Agents. For each agent (Architect, Backend Coder, Frontend Coder, ...) pick the model that will handle it. Different agents can use different models.

5. Create your first project

  1. Open Chat tab.
  2. Describe what you want in plain English or Russian, e.g.: "Create a WinUI 3 app for tracking daily expenses with a chart of monthly spend."
  3. Press Run. Watch the pipeline: Interpreter → Architect → Scaffolder → Coders → Tester → Builder → (Fixer) → Secretary.
  4. When done, open the output folder (path is shown in the log). Inside you'll find the generated project, a Git repo with per-stage commits, TZ.md (spec) and REPORT.md.

7. Troubleshooting

  • Ollama not reachable — check that ollama serve is running and the port matches Settings.
  • Model runs out of memory — pick a smaller quant (e.g. :7b-q4) or lower ContextWindow in agent settings.
  • Build fails repeatedly — the Fixer tries up to 3 times per stage. If it still fails, check REPORT.md and the raw model output in the output folder.
