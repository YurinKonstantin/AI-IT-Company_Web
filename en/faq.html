Frequently Asked Questions

Is it really free?

Yes. The application is free, and it uses local models via Ollama — you pay nothing for inference. The only "cost" is disk space and electricity.

Does it need internet?

Only for downloading models the first time. After that everything works offline.

What kind of projects can it build?

Today: WinUI 3 desktop apps, MonoGame games, ASP.NET/Console apps in C#, with xUnit tests. More project types are planned.

What hardware do I need?

The minimum tested config is Ryzen 5, 32 GB DDR4, 1 GB GPU running qwen2.5-coder:7b or :14b. Faster CPU/GPU and more RAM speed things up but are not required. For 14B models 32 GB RAM is strongly recommended.

Which models work best?

qwen2.5-coder:14b for coding agents; llama3.1:8b or gemma2:9b for interpretation and reporting. See the Quick Start table.

Can I use different models for different agents?

Yes — that's the whole point. Each agent has its own settings: model, temperature, context window, timeout. A small fast model can handle interpretation while a heavier one handles code generation.

Where are generated projects saved?

By default in %LocalAppData%\AiItCompany\Output\<projectId>. Each project has its own folder with the generated code, a Git repository with per-stage commits, TZ.md (spec) and REPORT.md.

Does the app modify my code without asking?

Only inside its own output folder. It never touches other places on your disk. If you point it at an existing project, it makes a full backup first.

What if a build fails?

The Error Fixer agent tries up to 3 times per stage, reading the compiler log and patching files. If it still fails, the pipeline reverts to the last successful git commit and continues with independent stages.

Can I use OpenAI / Anthropic / Groq instead of Ollama?

Not yet in the current release. Ollama is the only supported provider today. Support for OpenAI-compatible endpoints (LM Studio, OpenAI API, OpenRouter) is planned.

Is my code sent anywhere?

No. Everything happens locally between the app and your local Ollama instance. See Privacy Policy for details.

Can I customize the agent prompts?

Yes. Open Settings → Prompts, override any agent's system prompt. Leave empty to fall back to the default prompt from code.

Why C# / WinUI / MonoGame specifically?

Because that's the author's focus. The architecture is provider-agnostic — new agent roles and project types can be added by writing one class each.

How do I get help?

Open an issue on GitHub with your log and the raw model output. See Contribute for details on what to include.
